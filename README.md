# 🚚 ShipNow Admin Panel

A modern and responsive **Admin Dashboard** for the **ShipNow Courier Management System**, built with **React.js**. This application enables administrators to efficiently manage users, shipments, delivery operations, and overall system activities through a clean and intuitive interface.

---

## 📌 Features

- 🔐 Secure Authentication
- 👤 User Management
- 📦 Parcel Management
- 🚛 Delivery Personnel Management
- 📊 Dashboard Analytics
- 🔍 Search & Filter Functionality
- 📱 Fully Responsive Design
- ⚡ Fast Performance with React
- 🎨 Modern UI/UX
- 🔄 Real-time Status Updates

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/naimulislamsaikat/shipnow_admin.git
```

Move into the project folder

```bash
cd shipnow_admin
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

The application will run on

```
http://localhost:5173
```
